PRIVACY POLICY

プライバシーポリシー

この方針は、チャンネル運営者本人が使用する「逆説コイン 投稿管理」のYouTube投稿機能と、その説明サイトに適用します。

制定・更新日：2026年10月21日。アプリは接続準備中です。動画制作に使う別のサービス全体の方針を示すものではありません。

1. 使用するサービスとデータ

本ツールはYouTube API Servicesを利用します。本人の許可に基づき、次の情報を処理します。

  • 本人のPCで選択した動画・サムネイル、およびタイトル・概要欄・タグ・カテゴリ・公開日時などの投稿設定
  • 接続先の照合に使うチャンネルID、および本人が投稿した動画のID・本文・公開設定・予約状態
  • Google OAuthで取得するアクセス用・更新用の認証情報と、有効期限
  • アップロードの受領記録、再開位置、照合日時などの処理記録

Googleのパスワードは取得・保存しません。本人のチャンネルへの投稿管理を目的としており、第三者のチャンネル情報を収集するリサーチサービスではありません。

2. 利用目的

取得する情報は、本人が許可したチャンネルの照合、動画とサムネイルの送信、公開予約、結果の確認、認証の更新、失敗した送信の再開に使用します。承認した対象と異なるチャンネルへ投稿したり、重複アップロードを無条件で繰り返したりしないためにも処理記録を使用します。

この投稿機能は、Google APIから取得したデータを広告配信、データ販売、信用判断、AIモデルの学習に使用しません。

3. 保存場所と共有先

認証情報は本人のPC上で、本人のWindowsアカウントに紐づく暗号化機能を使って保存します。公開サイト、公開リポジトリ、チャット本文へ認証値を掲載しません。動画・投稿設定・受領記録も本人管理のPC上で扱います。

投稿を実行すると、動画・サムネイル・投稿設定・認証に必要な情報がGoogle／YouTubeへ送信されます。公開予約が受け付けられた動画は、本人が指定した設定に従ってYouTube上で公開されます。APIから取得したチャンネル・動画情報を、投稿機能から外部AIサービスへ転送する処理はありません。

Google／YouTube側での情報の取り扱いは、GoogleのプライバシーポリシーおよびYouTube利用規約にも従います。

4. 接続の取り消しとローカルデータの削除

本人はいつでもGoogleアカウントの接続済みアプリ設定から、このアプリへのアクセス許可を取り消せます。許可が無効になった場合、認証の更新に失敗したまま投稿を続けることはできません。

認証情報は利用を継続する間、許可された投稿管理のために保持します。利用をやめる場合やデータを消したい場合は、接続を取り消し、本人がPC上の認証保管データと不要なAPI受領情報を削除してください。PC上の情報を消しても、すでにYouTubeへ送信された動画やYouTube側のデータは削除されません。YouTube上の動画の変更・削除は、別途YouTube Studioから行ってください。

本ツールは運営者本人の内部ツールで、第三者の利用者情報を預かるサービスではありません。削除やデータの扱いについて問い合わせる場合は、下記の窓口を利用できます。

5. Google APIデータの利用範囲

Google APIから受け取る情報の利用と他のアプリへの転送は、Google API Services User Data PolicyのLimited Use要件を含む条件に従います。本人に説明した投稿管理の目的以外に、Google APIから取得した情報を利用しません。

6. この説明サイトについて

このサイトにはGoogleログイン、動画アップロード、問い合わせフォーム、広告、アクセス解析スクリプトを設置していません。サイトの運営者が、閲覧者のGoogle認証情報をこのサイトから取得することはありません。

公開にはGitHub Pagesを使用します。配信事業者のGitHubは、安全性の確保などのため閲覧者のIPアドレス等を記録する場合があります。詳しくはGitHubのプライバシーに関する声明を確認してください。

7. 問い合わせと変更

運営・開発：逆説コインのチャンネル運営者。質問・苦情はこの説明サイトの問い合わせ窓口で受け付けます。公開の窓口なので、認証情報、Googleのパスワード、非公開動画、個人情報は書き込まないでください。

機能やデータの取り扱いを変更した場合は、このページの内容と更新日を変更します。データを別の目的に使う場合は、必要な説明と本人の同意を先に行います。
